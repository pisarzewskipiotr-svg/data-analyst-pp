# Excel Projects — Portfolio analityczne

Zbiór projektów analitycznych wykonanych w Excelu, łączących wykształcenie w zakresie programowania i analizy danych z praktycznym doświadczeniem operacyjnym (praca magazynowa, uprawnienia na wózki widłowe).

Każdy projekt znajduje się w osobnym folderze i zawiera plik Excel oraz własny README z opisem metodologii i wniosków.

## Projekty

### 📦 [warehouse-abc-xyz-analysis](./warehouse-abc-xyz-analysis)
Analiza ABC/XYZ zapasów magazynowych — segmentacja 500 SKU wg wartości sprzedaży i zmienności popytu, macierz decyzyjna z politykami zapasów, wyliczenie Safety Stock, Reorder Point i EOQ.

**Technologie:** Excel (tabele przestawne, XLOOKUP, funkcje statystyczne, wykresy), Python (generowanie danych syntetycznych)

**Plik:** `analiza-abc-xyz-magazyn.xlsx`
